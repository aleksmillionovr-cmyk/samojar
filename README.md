# 💎 ROBUX SHOP — Telegram-бот + веб-админка

Бот магазина на **pyTelegramBotAPI**, админка на **Flask**. Всё — каталог, цены, тексты, кнопки, токены
и платёжки — правится в браузере, без правки файлов и без перезапуска.

## 🚀 Установка на сервер (одна команда)

Нужен чистый сервер на **Ubuntu 22.04/24.04 или Debian 11/12**. Зайди по SSH под root и выполни:

```bash
curl -fsSL https://raw.githubusercontent.com/aleksmillionovr-cmyk/samojar/claude/bot-deployment-admin-panel-72uvk9/install.sh | bash
```

Установщик за 2–4 минуты:

- поставит Python, библиотеки и бота в `/opt/robux_bot`;
- придумает пароль админки и покажет его в конце;
- включит автозапуск (systemd) — бот поднимется сам после перезагрузки сервера или сбоя;
- поставит **Caddy** и получит бесплатный HTTPS-сертификат Let's Encrypt прямо на IP сервера
  (запасной вариант — адрес вида `45-158-185-31.sslip.io`). Админка открывается по `https://`, пароль не летит открытым текстом;
- запустит бота от отдельного пользователя без прав root.

В конце он напишет адрес админки и пароль. Дальше всё делается в браузере:

1. **Подключения** → токен бота от @BotFather и свой Telegram ID (узнать: @userinfobot).
2. **Подключения → BoomKassa** → API-ключ; адрес вебхука отправить в поддержку BoomKassa.
3. **Настройки** → ник поддержки, способы оплаты. **Подписки / Услуги / Тексты** — по вкусу.

Свой домен вместо IP: `curl … | DOMAIN=shop.example.ru bash` (A-запись домена должна смотреть на сервер).

### Установка и обновление через GitHub (без SSH)

В репозитории есть кнопка установки: **Actions → «Установка на сервер» → Run workflow**.
Нужен секрет репозитория `SERVER_PASSWORD` (пароль root сервера), необязательно — `BOT_TOKEN`.

### Команды на сервере

| Команда | Что делает |
|---|---|
| `robux-bot status` | работает ли бот, адрес админки |
| `robux-bot logs` | журнал в реальном времени |
| `robux-bot restart` | перезапуск |
| `robux-bot update` | обновить до последней версии из GitHub (данные сохраняются) |
| `robux-bot password` | новый пароль админки, если забыл |
| `robux-bot backup` | архив заказов и настроек в `/root` |

## 🖥 Админка

| Раздел | Что внутри |
|---|---|
| 📊 **Сводка** | что осталось настроить, заказы к выдаче, выручка (сегодня / 7 / 30 дней), график за 14 дней, способы оплаты, топ позиций, состояние бота, кнопка «техперерыв» |
| 🧾 **Заказы** | фильтры, поиск (№, ник Roblox, Telegram, позиция), выгрузка в CSV. Карточка заказа: «✅ Выдано», отправить код или сообщение, «💰 отметить оплаченным», ручной статус, ник, заметка, возврат звёзд |
| 👥 **Покупатели** | все, кто запускал бота: сколько потратил, заказы, последняя активность, личное сообщение от бота, блокировка, заметка |
| 📣 **Рассылка** | всем / покупателям / ещё не купившим / тест админам; разметка, кнопка-ссылка, живое превью, прогресс и остановка |
| 💎 **Подписки** и 🛍 **Услуги** | добавить, изменить, скопировать, скрыть, удалить, порядок ↑↓, живое превью карточки, тариф BoomKassa |
| ✍️ **Тексты** | все сообщения бота: приветствие, разделы, поддержка, «оплата прошла», просьба ника, «заказ выполнен», техперерыв и др. — с превью |
| ⚙️ **Настройки** | название, валюта, поддержка, стикер, подписи кнопок меню, способы оплаты, курс звезды, техперерыв, срок жизни неоплаченного заказа |
| 🔌 **Подключения** | токен бота, ID админов, BoomKassa, платёжка Telegram, CryptoBot, закрытый канал. Кнопки проверки каждого подключения |
| 🛡 **Система** | смена пароля, резервные копии, откат последнего изменения каталога, журнал ошибок, перезапуск бота |

Защита: вход по паролю (5 ошибок → блок на 10 минут), CSRF на всех формах, HTTPS, токены не показываются целиком,
смена пароля завершает чужие сессии, перед каждым сохранением каталога делается копия.

## 💳 Оплата

| Способ | Что нужно |
|---|---|
| ⭐ **Telegram Stars** | работает сразу |
| 💳 **Карта / СБП (BoomKassa)** | API-ключ, тарифы и секрет вебхука (см. ниже) |
| 💳 **Карта через платёжку Telegram** | provider token из @BotFather → Payments |
| 💵 **USDT (CryptoBot)** | токен из @CryptoBot → Crypto Pay → Create App |

### BoomKassa

Как устроена их оплата: бот создаёт ссылку на оплату по **тарифу**, покупатель платит картой или через СБП,
BoomKassa присылает вебхук `payment.succeeded` с подписью HMAC-SHA256, бот подтверждает заказ и пишет покупателю.

1. В личном кабинете BoomKassa → **API и интеграция** запроси доступ к «Ссылкам на оплату» и выпусти **API-ключ**.
2. Попроси поддержку BoomKassa завести **тарифы** на суммы твоих позиций (BoomKassa не принимает произвольные суммы)
   и настроить **вебхук** на `https://<адрес-админки>/webhook/boomkassa`. Они выдадут **секрет вебхука**.
3. В админке → **Подключения → BoomKassa** вставь ключ и секрет, нажми «Проверить ключ и обновить тарифы».

Бот сам подберёт тариф с той же суммой, что и цена позиции, или возьмёт тариф, выбранный в карточке позиции.
Если подходящего тарифа нет, кнопка BoomKassa для этой позиции не показывается. Пока не задан секрет вебхука,
заказы можно отмечать оплаченными вручную в карточке заказа.

## Команды в Telegram (для админов)

| Что | Как |
|---|---|
| Новый заказ | приходит в личку с кнопкой **✅ Выдано** |
| Отправить код покупателю | `/give 15 ABCD-1234` |
| Очередь на выдачу | `/orders` |
| Статистика за сутки | `/stats` |
| Ссылка на админку | `/admin` |
| ID стикера для приветствия | отправь боту любой стикер |

Покупателям доступны `/start`, `/orders` (мои заказы), `/help`.

## Файлы

| Файл | Что это |
|---|---|
| `bot.py` | бот, запускает и админку |
| `admin.py`, `templates/`, `static/` | веб-админка |
| `store.py` | общее ядро: настройки, база, каталог, тексты |
| `boomkassa.py` | оплата через BoomKassa |
| `catalog.py` | стартовые тексты и цены (копируются в `data/catalog.json` при первом запуске) |
| `install.sh`, `robux-bot.sh` | установщик и помощник для сервера |
| `data/` | на сервере: заказы (`orders.db`), каталог, подключения (`config.json`), журнал |

Локальный запуск для разработки: `pip install -r requirements.txt`, создать `.env` с `ADMIN_PASSWORD=…` и `ADMIN_HOST=127.0.0.1`,
затем `python bot.py` → админка на http://localhost:8080.

## Важно

- По правилам Telegram цифровые товары в ботах нужно продавать за **Telegram Stars**; внешние платёжки — на твой риск.
- Правила Roblox запрещают продажу робуксов в обход официальных способов: аккаунты и группы для выдачи могут заблокировать.
- Вернуть стартовые тексты и цены: останови бота, удали `data/catalog.json`, запусти снова. Заказы не пропадут.
