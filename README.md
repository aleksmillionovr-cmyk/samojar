# 💎 ROBUX SHOP: Telegram-бот + веб-админка

Бот на **pyTelegramBotAPI (telebot)**, админка на **Flask**. Обе части запускаются одной командой.

## Файлы

| Файл | Что это |
|---|---|
| `bot.py` | Бот. Запускает и админку |
| `admin.py` | Веб-админка |
| `store.py` | Общая часть: заказы, каталог, сборка текстов |
| `catalog.py` | Стартовые тексты и цены. Копируются в `catalog.json` при первом запуске |
| `catalog.json` | Текущий каталог. Создаётся сам, меняется из админки |
| `orders.db` | Заказы, создаётся сам |
| `.env` | Токены и пароль админки |

## Запуск

1. Создай бота в **@BotFather** и скопируй токен.
2. Скопируй `.env.example` в `.env`. Заполни `BOT_TOKEN`, `ADMIN_ID` (свой ID узнаешь в @userinfobot) и **`ADMIN_PASSWORD`** (минимум 8 символов).
3. Нужен Python 3.10 или новее:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
4. Открой админку в браузере:
   - на том же компьютере: **http://localhost:8080**;
   - с телефона или другого устройства: **http://IP-сервера:8080**. На VPS открой порт 8080 в файрволе.

## 🖥 Админка

- **📊 Сводка**: заказы, которые ждут выдачи, выручка за сегодня, 7 и 30 дней, разбивка по способам оплаты, топ позиций.
- **🧾 Заказы**: фильтры (ждут выдачи, выполнены, все оплаченные, отменённые) и поиск по номеру, нику Roblox или Telegram. Кнопка **✅ Выдано** отправляет покупателю уведомление. **📩 Отправить код** передаёт код подарочной карты, ссылку или сообщение и может сразу закрыть заказ.
- **💎 Подписки и 🛍 Услуги**: можно добавлять, править, менять порядок стрелками ↑ ↓, скрывать из бота и удалять. При правке справа **живое превью**, точно как покупатель увидит карточку в Telegram. Кнопки форматирования (жирный, курсив, зачёркнутый, код, спойлер) работают с выделенным текстом.
- **✍️ Тексты**: приветствие, шапки разделов, поддержка, просьба прислать ник. Для каждого текста есть превью.
- **⚙️ Настройки**: название магазина, знак валюты, ник поддержки, стикер на /start, включение и выключение Stars, рублей и USDT, курс звезды. Справа видно, какие токены из `.env` подключены.

**Изменения из админки бот подхватывает сразу, без перезапуска.**

Защита от ошибок:
- админка проверяет HTML-разметку и не сохранит текст, на котором Telegram выдаст ошибку (незакрытый тег, одиночный `<` или `&`), а также слишком длинную карточку;
- перед каждым сохранением прошлая версия каталога копируется в `catalog.backup.json`.

Безопасность:
- вход по паролю, после 5 неверных попыток вход блокируется на 10 минут;
- все формы защищены CSRF-токеном;
- токены из `.env` в админке не показываются.

Если админка будет доступна из интернета, лучше поставить перед ней HTTPS (например, Caddy или nginx с Let's Encrypt), иначе пароль передаётся открытым текстом. Второй вариант: поставь `ADMIN_HOST=127.0.0.1` и заходи через SSH-туннель.

## 💳 Оплата

1. **⭐ Stars** работают сразу, без провайдера.
2. **💳 Рубли**: в @BotFather открой `/mybots`, выбери бота, затем **Bot Settings → Payments** и провайдера с пометкой **TEST**. Токен вставь в `PROVIDER_TOKEN`. Тестовые карты у каждого провайдера свои (у Stripe TEST это `4242 4242 4242 4242`, любой срок и CVC).
3. **💵 USDT**: в **@CryptoTestnetBot** открой Crypto Pay → Create App и скопируй токен в `CRYPTO_PAY_TOKEN`, оставь `CRYPTO_TESTNET=1`. Для боевого режима сделай то же самое в **@CryptoBot** и поставь `CRYPTO_TESTNET=0`.

Способы оплаты включаются и выключаются галочками в админке (Настройки). Токены задаются только в `.env`, после их правки перезапусти бота.

## Команды в Telegram (для ADMIN_ID)

| Что | Как |
|---|---|
| Новый заказ | Приходит в личку с кнопкой **✅ Выдано** |
| Отправить код покупателю | `/give 15 ABCD-1234` |
| Последние заказы | `/orders` |
| ID стикера для приветствия | Отправь боту любой стикер |

## Важно

- По правилам Telegram цифровые товары в ботах нужно продавать за **Telegram Stars**. Провайдер карт здесь стоит для теста.
- Правила Roblox запрещают продажу робуксов в обход официальных способов. Аккаунты и группы, через которые идёт выдача, могут заблокировать.
- Чтобы вернуть стартовые тексты и цены, останови бота, удали `catalog.json` и запусти снова. Заказы при этом не пропадут.
- Админку можно запустить отдельно от бота: `python admin.py`.
